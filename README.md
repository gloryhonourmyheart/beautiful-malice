# 漂亮的恶意：入学日

> 单教室场景 · 第三人称 · 2-3 分钟 · 双结局
> VibeHacks #06「Vibe Coding for 3D 游戏世界」参赛作品

**一句话**：你是新来的转学生张知安，走进一间没人欢迎你的贵族教室——穿过三道人为的刁难，坐到最后一排那个属于你的空位，就算赢。

---

## 快速开始

```bash
npm install        # 可选，本项目零依赖也能跑
npm run dev        # 打开 http://localhost:5173
```

项目是**零构建**的：three.js 在 `vendor/` 里，`npm run dev` 只是起一个静态服务器（`serve.mjs`），改完代码刷新即生效。

调试：`http://localhost:5173/?skipIntro` 跳过开场；`?intro` 单独调开场镜头。
游戏内按 `` ` `` 打开调试面板（气场值 / 坐标 / 阶段），按 `R` 重开。

构建静态包（部署线上链接用）：`npm run build`，产物在 `dist/`。

## 操作

| 键 | 作用 |
|---|---|
| `WASD` / 方向键 | 移动 |
| 鼠标拖动 | 环视（第三人称相机） |
| `A` | **障碍 1：黑板擦袭来时向左闪避（1 秒时限）** |
| `E` | 互动（清理纸团 / 捡书 / 坐下） |
| `1` `2` | 对话选项 |
| `R` | 重新开始 |

## 流程（2:10 基准）

1. **开场 24 秒**：相机扫过靠窗空位 → 中排 → 后排角落，旁白三句
2. **障碍 1 · 黑板擦突袭**（第三排中段）：1 秒内按 `A` 向左闪避，成功 +1 / 被砸中 −1；成功时靠窗的权时宪第一次抬眼
3. **障碍 2 · 纸团堵路**（后排过道）：1.2 秒内按 `E` 清理通路，成功 +1 / 打滑 −1
4. **障碍 3 · 搭讪邀坐**（目标座位旁）：二选一——婉拒但坚定 +2 / 犹豫退让 −2
5. **结局**：气场值 ≥ 0 成功入座，< 0 未能立足

> 气场值不在界面上显示。你做对了，靠窗那个人会抬眼看你；你做错了，全班会笑。
> 数值设计：三关全对 +4；只要有一次失误 + 一次退让就会掉到 0 以下。成功与失败各占一半。

## 目录（谁改哪里，别越界）

```
src/
  main.js              流程编排、触发区、结局演出     ← A
  world/classroom.js   教室、课桌、道具、碰撞体        ← B
  world/character.js   程序化低多边形人物              ← B
  systems/controls.js  第三人称移动与相机              ← A
  ui/hud.js            字幕、选项、QTE、结局卡         ← A
  audio.js             WebAudio 合成音效（无需素材）    ← C
  story/lines.js       全部台词与数值                  ← C
  style.css            界面样式                        ← C
```

**改剧情不用碰代码**：所有台词、选项文案、气场值、结局文案都在 `src/story/lines.js`。
