# 漂亮的恶意：入学日

> 单教室场景 · 第三人称 · 2-3 分钟 · 双结局
> VibeHacks #06「Vibe Coding for 3D 游戏世界」参赛作品

**一句话**：你是新来的转学生，走进一间没人欢迎你的贵族教室——穿过三道人为的刁难，坐到最后一排那个属于你的空位，就算赢。

---

## 快速开始

```bash
npm install
npm run dev        # 打开 http://localhost:5173
```

调试用参数：`http://localhost:5173/?skipIntro` 跳过开场镜头直接进游戏。
游戏内按 `` ` `` 打开调试面板（气场值 / 坐标 / 阶段），按 `R` 重开。

构建静态包（给线上链接 / 无网现场用）：

```bash
npm run build      # 产物在 dist/，可直接双击 index.html 或丢到任意静态托管
```

## 操作

| 键 | 作用 |
|---|---|
| `WASD` / 方向键 | 移动 |
| 鼠标拖动 | 环视（第三人称相机） |
| `E` | 互动（捡书 / 踢纸团 / 坐下） |
| `1` `2` | 对话选项 |
| `R` | 重新开始 |

## 流程（2:10 基准）

1. **开场 24 秒**：相机扫过靠窗空位 → 中排 → 后排角落，旁白两句
2. **障碍 1**：前排男生伸腿拦路 → 二选一（±1）
3. **障碍 2**：后排纸团挡路 → 1.2 秒 QTE（±1）
4. **障碍 3**：邻座金发男搭腿占座 → 二选一（−3 / +2）
5. **结局**：气场值 ≥ +1 成功入座，否则未能立足

> 气场值不在界面上显示。做对了，窗边那个人会抬眼看你；做错了，全班会笑。

## 目录（谁改哪里，别越界）

```
src/
  main.js              流程编排、触发区、结局演出     ← A
  world/classroom.js   教室、课桌、道具、碰撞体        ← B
  world/character.js   程序化低多边形人物              ← B
  systems/controls.js  第三人称移动与相机              ← A
  ui/hud.js            字幕、选项、QTE、结局卡         ← A
  audio.js             WebAudio 合成音效（无需素材）    ← C
  story/lines.json     全部台词与数值                  ← C
  style.css            界面样式                        ← C
```

**改剧情不用碰代码**：所有台词、选项文案、气场值、结局文案都在 `src/story/lines.json`。
