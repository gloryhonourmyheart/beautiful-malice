## 一、空间即阶级：教室平面图

**教室 12m × 10m，讲台在 Z=0，玩家从讲台侧的前门进，目标座位在最深处的右后角。**
从门到座位的 18 米，就是这座学校的全部阶层。

       │ [前门]                      │   ← 玩家出生点 (-4.5, 0.6)

       │                             │      旁边空置金皮椅，无人敢坐
Z=4.0  │ ▣ ▣ ▣ ║ ▣ ▣ ▣  第2排      │   ← ║ 中间过道，障碍1：男生伸腿封路
Z=5.6  │ ▣ ▣ ▣ ║ ▣ ▣ ▣  第3排      │
Z=7.2  │ ▣ ▣ ▣ ║ ▣ ▣ ▣  第4排      │
Z=8.6  │ ▣ ▣ ▣ ║ ▣ ▣ ▣  第5排      │   ← 障碍2：纸团堵在 (0, 8.0)
       │              [目标]        │   ← 目标座位 (4.5, 8.6) 右后角

| 物件 | 坐标 | 说明 |
|---|---|---|
| 玩家出生点 | (-4.5, 0.6) | 前门内侧，面朝 +Z |
| 权时宪 | (-4.5, 2.4) | 全场唯一穿深色西装、不开灯也看得清的人 |
| 空置金皮椅 | (-4.5, 3.2) | 皮质 + 一个金属水杯，永远没人坐 |
| 障碍 1 男生 | (-0.9, 4.0) | 椅背后仰 30°，腿架到 (0.9, 4.0) 桌沿 |

**走速定 1.6 m/s**（不是 4m/s）。教室要"走得慢"，慢才有压迫感，也顺手把时长撑到 2 分钟以上。

## 二、时间轴（锁定 2:10 为基准）

| 时间段 | 内容 | 强制的时长下限 |
|---|---|---|
| 0:00–0:25 | 开场横移镜头 + 旁白 | **25s，不可跳过**（可加"跳过"但默认播完） |
| 0:25–0:40 | 玩家走到第二个过道口 | 走路本身约 8s |
| 0:40–1:00 | 障碍 1 对话 + 选择 + 结果演出 | 对话打字机必读，选项出现后不自动推进 |
| 1:00–1:20 | 绕过 → 后排过道 | 约 6s |
| 1:20–1:35 | 障碍 2 QTE + 结果演出 | QTE 窗口 1.2s，演出 4s |
| 1:35–2:00 | 障碍 3 对话 + 选择 + 结果演出 | 三段台词，不可快进 |
| 2:00–2:20 | 落座 + 结局演出 + 结局卡 | 演出 8s 不可跳过 |

> **为什么要设"不可跳过"**：如果玩家手快，全程 1:30 就结束，demo 会显得很薄。上面四个强制点把下限锁在 2:10。上限靠玩家犹豫自然到 2:40。

## 三、气场值：只给反馈，不给数字

**屏幕上永远不显示数值。** 玩家靠三处"环境反馈"判断自己做得对不对——这是整个 demo 最省钱也最有效的设计。

| 节点 | 好选择（+） | 坏选择（−） |
|---|---|---|
| 障碍 1 | 男生收回腿 + **窗边的权时宪抬眼**（头转 15°） | 几声低笑 + 书本落地 |
| 障碍 2 | 纸团进垃圾桶 + 短发男"啧"一声 | 打滑踉跄 + 后排哄笑 |
| 障碍 3 | **全班安静 0.5 秒**（只剩空调声） | 几个男生交换眼神，笑 |

权时宪只在玩家做对时抬眼——**他是这套隐藏数值唯一的可视化仪表**。玩家不知道自己加了几分，但知道自己被看见了。

### 数值表（v2 已调整）

| 选择 | 分值 |
|---|---|
| 障碍 1 · 示弱绕路 | −1 |
| 障碍 1 · 正面回怼 | +1 |
| 障碍 2 · QTE 成功 / 失败 | +1 / −1 |
| 障碍 3 · 妥协服软 | **−3**（原案 −2） |
| 障碍 3 · 直接硬刚 | +2 |

**结局阈值：气场值 ≥ +1 → 成功入座。**

八种组合（好/坏/好…）：

| 障碍1 | 障碍2 | 障碍3 | 总分 | 结局 |
|---|---|---|---|---|
| +1 | +1 | +2 | +4 | 成功 |
| +1 | +1 | −3 | −1 | **失败** |
| +1 | −1 | +2 | +2 | 成功 |
| +1 | −1 | −3 | −3 | **失败** |
| −1 | +1 | +2 | +2 | 成功 |
| −1 | +1 | −3 | −3 | **失败** |
| −1 | −1 | +2 | 0 | **失败** |
| −1 | −1 | −3 | −5 | **失败** |

成功 3 种、失败 5 种。**只要最后一关服软，就必定失败**——这正是这个故事的意思：前两次可以失误，最后一次不能低头。

> 想更宽容就把阈值改回 0（失败变 3 种），改一个数字的事。

## 四、逐场台词与演出

### 场 1 · 开场（0:00–0:25）

**镜头**（一条轨道，三个关键帧，缓入缓出）：
1. 从靠窗黄金区起（0–8s）：皮质座椅、金属水杯、空着的位子——**先拍空位，不拍人**
2. 横移到中间（8–17s）：男生们笔挺的校服、交错的眼神，**没有人看你**
3. 压到后排角落（17–24s）：刻满涂鸦的桌面、纸团、倒扣的练习册
4. 切黑，标题浮现：**漂亮的恶意：入学日**

**旁白**（冷淡中性，读得慢，句间停 0.8s）：
> "在这里，座位的距离，就是阶层的距离。
> 有些规矩没人明说，但所有人都在遵守。"

**→ 点击开始。切到前门，第三人称背后视角。**

### 场 2 · 障碍 1（0:40–1:00）

玩家走到第二个过道口，男生把椅子往后一仰，长腿横过整条通道。镜头微微下沉（暗示被俯视）。

> **男生**（抬下巴，散漫）："站住。转学生？这条路，不是你这种人能走的。"

- **A「示弱绕路」**："抱歉，我走侧边过。"
  → 侧身挤进桌缝，男生脚尖轻挑，书掉在地上。**气场 −1**。周围低笑。玩家需要自己把书捡起来（按 E），耽误 3 秒——**这个惩罚比数值更疼**。
- **B「正面回怼」**："教室是你家开的？路还不让人走了？"
  → 男生愣半秒，腿收回去，椅子"哐"一声落正。**气场 +1**。
  → **切 0.6 秒特写：窗边，权时宪抬眼。**（全 demo 第一个高光，给他一个 0.6 秒的正面镜头，值）

### 场 3 · 障碍 2（1:20–1:35）

走过后排过道，纸团和练习册横在地上，短发男靠在椅背上看戏。

- 屏幕中央出现提示：**`E` 踢开**（1.2 秒窗口，超时自动判失败）
- **成功**：一脚把纸团踢进角落垃圾桶（有个"进桶"的音效，很爽），练习册被顺带踢开。**气场 +1**。短发男"啧"。
- **失败/超时**：踩上去打滑，踉跄两步，书散一地。**气场 −1**。后排哄笑。

### 场 4 · 障碍 3（1:35–2:00）

走到座位前，金发男的腿搭在你的桌板上，椅子被膝盖顶着，拉不开。

> **金发男**（歪头笑）："哟，还真敢走到这儿来？这片的规矩，没人跟你说过？"

- **A「妥协服软」**："我刚来，什么规矩？"
  → "一周早餐，加笔记。答应就让你坐。" 女主点头。**气场 −3**。他笑着把腿放下——**但椅子只挪开一半**，你得侧着挤进去。
- **B「直接硬刚」**："我坐我的座位，跟你的规矩没关系。"
  → 他伸手推你肩膀 → **镜头切**：侧身（0.3s），反手按住桌沿（0.5s），腿被顶下去（0.4s）。
  → **打斗全程用镜头切 + 音效 + 局部特写，不做完整动作动画。** 这是 7 小时里唯一能做出"打戏"的办法。
  → **气场 +2**。他脸色变了变。**全班安静 0.5 秒**（只剩空调声，这一下比任何音乐都响）。

### 场 5 · 结局（2:00–2:20）

**成功（≥ +1）**
- 拉椅、坐下、书包进桌洞、课本平铺——四个动作，每个 0.5 秒，节拍要稳
- 窃笑声一层层退下去（音频：多轨人声逐一静音）
- 镜头缓推到窗边，权时宪侧头看你，眼里有点新鲜感
- 女主内心 OS（川渝口音，很轻）："总算坐下了。管他什么规矩，能好好学习就行。"
- 结局面板：**关卡完成 · 成功入座**

**失败（< +1）**
- 站在座位旁，椅子拉不开。前后几个男生围着说话（只做环境人声，不做对白）
- **上课铃响**，门被推开，一道光切进来（**老师只出声，不出现**："那位同学，为什么站着？"）
- 全班哄笑，女主攥紧书包带
- 内心 OS："这地方……比我想的还要难待。"
- 结局面板：**任务失败 · 未能入座**｜`R` 重新开始

## 七、三个技术风险（现在就要定）

1. **第三人称 = 要角色模型 + 走路/站立/坐下三套动画。** 建议：低多边形角色 + Mixamo 免费动作重定向。**如果 12:00 还没有能动的人形，立刻改第一人称**（省掉全部角色动画，代价是看不到张知安的背影）。这个决定必须在 12:00 前下。
2. **30 套桌椅**用 `InstancedMesh`，别逐个创建。B 只要写一个 `createDesk()`，剩下靠循环摆坐标。
3. **不要做真实阴影**。一盏方向光 + 一张假的地面暗角贴图，帧率立刻稳。教室的可信度来自"光从左侧窗进来"，不来自阴影精度。

## 八、路演时只说这三句

1. "整间教室 30 个座位，只有一个是空的——**空位在哪，就是你在哪。**"
