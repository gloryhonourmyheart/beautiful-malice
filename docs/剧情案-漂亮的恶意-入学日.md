# 《漂亮的恶意：入学日》剧情案 v3（黑板擦闪避版）

（VibeHacks #06 参赛版 · 单教室场景 · 第三人称叙事 · 全男性 NPC 刁难 · 7 小时开发适配）

---

## 一、项目基础设定

- **作品定位**：单场景 3D 互动叙事 Demo，改编自热门 IP《漂亮的恶意》第一集「转学生」名场面
- **游玩时长**：单局 2-3 分钟，支持重复游玩解锁不同结局
- **核心玩法**：第三人称行走探索 + 即时闪避 QTE + 交互清理 QTE + 对话分支选择
- **核心目标**：操控转学生张知安，从教室前门走到后排角落的专属座位并成功落座
- **核心数值**：隐藏属性「气场值」（初始 0），正向操作加分、负向操作扣分，最终决定结局走向

## 二、开场叙事（0:00–0:25 · 镜头化阶层铺垫）

全程无直白说教，通过镜头运动与人群站位隐晦传递等级规则。

1. **镜头一 · 顶层核心区（靠窗）**：皮质座椅空置着，周围簇拥着三四名男生——有人侧身低声汇报，有人随手递上水杯。明明无人敢坐，空位自带压迫感（权时宪的专属位置）
2. **镜头二 · 中层观望区（教室中部）**：校服笔挺、坐姿倨傲，不主动围上去，但用余光偷瞄核心区，彼此用眼神划分势力范围
3. **镜头三 · 底层边缘区（后排角落）**：桌面刻满涂鸦，地面散落纸团与倒扣的练习册，几个男生零散而坐，彼此隔着明显空隙，像被整间教室默认的规则隔绝在外
4. **收尾**：冷淡中性旁白——「在这里，座位的距离，就是阶层的距离。有人被簇拥着，有人被隔开。有些规矩没人明说，但所有人都在遵守。」镜头拉回前门，黑屏出标题，点击开始

## 三、基础规则

- 角色：张知安（黑长直、银边发夹、蓝牙耳机、简约书包的川渝转学生）
- 操作：WASD 移动 · 鼠标视角 · E 交互 · A 闪避
- 任务常驻：**「走到你的座位并坐下」**
- 判定：3 处障碍事件改变气场值；最终 ≥ 0 成功 / < 0 失败

## 四、三道障碍（层层递进）

### 障碍 1 · 盲区黑板擦突袭（第三排中段）

前排挑事男生躲在讲台侧方的视角盲区，突然扔出黑板擦；屏幕右侧红色感叹号预警 + 短促风声。**1 秒内按 A 向左闪避。**

- **成功（+1）**：侧身偏头，黑板擦擦着发丝飞过，"啪"地砸在身后柜门上。她皱眉回头，挑事男生立刻低头翻书装无事。靠窗核心区里原本低头的人第一次抬眼，视线落在她背影上
- **失败（−1）**：砸中肩膀，书本哗啦散落。压低的哄笑 + 一声口哨。弯腰捡书，节奏被彻底打断

### 障碍 2 · 后排纸团堵路（后排过道）

三四个揉皱纸团 + 倒扣练习册完全堵路；短发男生抱臂冷眼旁观——明显是他扔的。**按 E 清理通路。**

- **成功（+1）**：不弯腰、不绕路。抬脚把纸团依次踢到墙角垃圾桶旁，脚尖把练习册拨回桌下，全程没有停步。看戏的男生啧了一声，戏谑变成意外
- **失败（−1）**：踩在纸团上打滑踉跄，书又掉出几本。后排哄笑，有人模仿她差点摔倒的动作

### 障碍 3 · 后排男生搭讪邀坐（目标空位旁）

邻座男生转着笔，把椅子往空位挪了半分，拍着椅面轻浮搭话：

> 「哟，新同学？别站着啊，坐这儿来，以后在班里哥罩着你。」

- **A 婉拒但坚定（+2）**：「不用了，谢谢。这是我的座位，麻烦让一下。」她扶住椅背，眼神没有退让。男生笑容僵住，被直视得讪讪收回手，把椅子挪回原位——落座主动权到手
- **B 犹豫退让（−2）**：「……我、我还是找别的位置吧。」男生得寸进尺拉住她书包带：「别啊，坐一下怎么了？给个面子。」周围起哄，她被缠住，彻底陷入被动

## 五、双结局

### 成功 · 稳稳落座（气场值 ≥ 0）

拉开椅子坐下，书包进桌洞，课本平铺桌面。动作很慢、很稳，仿佛一路的刁难都不值一提。窃笑声渐渐平息——靠窗那个始终冷淡的身影第一次侧过头，目光越过整间教室落在她身上，带着几分玩味的新鲜感。

内心 OS（淡川渝口音）：「总算坐下了。管他什么花样，能好好学习就行。」
**关卡完成 · 成功入座**

### 失败 · 无法立足（气场值 < 0）

站在空位旁被围着调侃，椅子被抵着没法坐下。上课铃骤响，老师皱眉：「那位同学，上课了为什么不坐下？」全班安静一秒，随即爆发哄笑。

内心 OS（发闷、无力）：「这地方……比我想的还要难待。」
**任务失败 · 未能入座**（可重新开始）
